# This repository has moved

This project now lives at **[Paloma](https://github.com/yonatang8675/Paloma)**.

Paloma is a configurable two-stage pipeline for TESS Full Frame Image (FFI) processing. It removes scattered light from raw telescope frames using a dehazing-based cleaning stage, then applies optimal image subtraction to isolate variable sources, detect residuals, and extract light curves.

```text
git clone https://github.com/yonatang8675/Paloma.git
```

This repository is no longer maintained. Use [yonatang8675/Paloma](https://github.com/yonatang8675/Paloma) for the code, documentation, and ongoing development.
